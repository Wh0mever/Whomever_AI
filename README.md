# WHOMEVER AI - Интеллектуальный Telegram Бот

**Передовой ИИ-помощник на базе GPT-4.1 с поддержкой групповых чатов, голосовых ответов и контекстной памяти.**

## 🚀 Основные возможности

### 🤖 Интеллектуальное общение
- **GPT-4.1** - самая новая модель OpenAI с поддержкой до 1M токенов
- **24 специализированных персонажа** (врач, юрист, программист, психолог и др.)
- **Адаптивная личность** - подстраивается под стиль каждого пользователя
- **Контекстная память** - помнит историю диалогов и участников

### 👥 Групповые чаты
- **Система вызова !WHOMEVER** - бот отвечает только при прямом обращении
- **Умное распознавание** участников и их ролей
- **Контекст беседы** - понимает о чем идет речь в группе
- **Статистика и аналитика** активности участников

### 🎤 Голосовые возможности
- **TTS (Text-to-Speech)** - преобразование текста в речь
- **6 различных голосов** OpenAI (Alloy, Echo, Fable, Onyx, Nova, Shimmer)
- **Real-time Voice Chat** через WebSocket API
- **Whisper интеграция** для распознавания речи

### 🎨 Мультимедиа
- **DALL-E 3** для генерации изображений
- **GPT-4.1 Vision** для анализа изображений и документов
- **Редактирование изображений** и создание вариаций
- **Обработка файлов** (PDF, DOC, изображения, аудио, видео)

### 🔍 Поиск и анализ
- **Веб-поиск** через FetchSERP API
- **Анализ документов** любых форматов
- **Поисковые подсказки** и релевантные результаты

### ⚡ Производительность
- **Worker Pool** на 10 потоков для параллельной обработки
- **Асинхронная архитектура** с aiosqlite
- **Оптимизированная обработка** до 10 запросов одновременно

### 🔒 Безопасность
- **Переменные окружения** для API ключей
- **Система ролей** с особыми правами для основателя
- **Rate limiting** и защита от спама

## 📦 Установка

### Требования
- Python 3.8+
- FFmpeg (для обработки аудио/видео)
- SQLite3

### Быстрый старт

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-repo/whomever-ai
cd whomever-ai
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте .env и добавьте ваши API ключи
```

4. **Получите необходимые API ключи:**
   - [Telegram Bot Token](https://t.me/BotFather)
   - [OpenAI API Key](https://platform.openai.com/api-keys)
   - [FetchSERP API Key](https://www.fetchserp.com/) (опционально)

5. **Запустите бота:**
```bash
python bot.py
```

## ⚙️ Конфигурация

### Переменные окружения (.env)
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OPENAI_API_KEY=your_openai_api_key
FETCHSERP_API_KEY=your_fetchserp_api_key
BOT_ADMIN_ID=your_user_id
```

### Настройка персонажей
Редактируйте список `CHARACTERS` в `config.py` для добавления новых специалистов.

### Настройка голосов
Выберите из 6 доступных голосов OpenAI:
- **alloy** - нейтральный
- **echo** - мужской
- **fable** - британский акцент
- **onyx** - глубокий мужской
- **nova** - женский
- **shimmer** - мягкий женский

## 🎯 Использование

### В приватных чатах
- Просто напишите сообщение боту
- Используйте кнопки для быстрого доступа к функциям
- Настройте персонажа и стиль общения

### В групповых чатах
- **!WHOMEVER** - вызвать бота
- **@whomever** - упомянуть бота
- Отвечайте на сообщения бота для продолжения диалога

### Команды
- `/start` - приветствие и настройка
- `/help` - справка по командам
- `/search <запрос>` - поиск информации
- `/image` - генерация изображений
- `/stats` - статистика чата (в группах)
- `/context` - контекст беседы

## 🏗️ Архитектура

```
bot.py              # Основной файл бота
├── config.py       # Конфигурация и настройки
├── database.py     # Асинхронная база данных
├── openai_api.py   # Интеграция с OpenAI
└── search_api.py   # Поисковый API
```

### Основные компоненты
- **TelegramBot** - главный класс бота
- **Database** - асинхронная работа с SQLite
- **OpenAIAPI** - интеграция с GPT-4.1, DALL-E, TTS
- **WorkerPool** - параллельная обработка запросов
- **ContextManager** - управление контекстом диалогов

## 👑 Особые возможности для основателя

Пользователь с ID, указанным в `BOT_ADMIN_ID`, получает:
- Неограниченный доступ ко всем функциям
- Особое распознавание как "Founder/CEO WHOMEVER (Shokha)"
- Приоритетная обработка запросов
