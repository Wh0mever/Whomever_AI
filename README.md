# Telegram-бот с DeepseekCHAT

Интеллектуальный ассистент на базе DeepseekCHAT с возможностью выбора различных персонажей и настройки стиля общения.

## Возможности

- 20 различных персонажей-специалистов
- Настраиваемый стиль общения
- Различные уровни глубины анализа
- Сохранение истории диалогов
- Удобное управление через кнопки

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <repository-name>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию:
   - Откройте файл `config.py`
   - Замените `YOUR_TELEGRAM_BOT_TOKEN` на токен вашего бота от @BotFather
   - DeepseekCHAT API ключ уже настроен

## Запуск

```bash
python bot.py
```

## Использование

1. Запустите бота в Telegram: `/start`
2. Используйте кнопки меню для:
   - Выбора персонажа
   - Настройки стиля общения
   - Изменения глубины анализа
3. Отправляйте сообщения боту для получения ответов

## Структура проекта

- `bot.py` - основной файл бота
- `config.py` - конфигурация и настройки
- `database.py` - работа с базой данных
- `deepseek_api.py` - интеграция с DeepseekCHAT API
- `requirements.txt` - зависимости проекта

## Требования

- Python 3.7+
- Telegram Bot Token (получить у @BotFather)
- DeepseekCHAT API ключ (уже настроен)
