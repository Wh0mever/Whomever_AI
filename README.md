# Telegram-бот с OpenAI GPT-4o

Интеллектуальный ассистент на базе OpenAI GPT-4o с возможностью выбора различных персонажей и настройки стиля общения.

## Основные возможности

- Выбор персонажа (психолог, бизнес-консультант и т.д.)
- Настройка стиля общения (формальный/неформальный)
- Настройка глубины анализа (краткий/детальный)
- Сохранение истории диалогов
- Персонализированные настройки для каждого пользователя

## Технические требования

- Python 3.8+
- SQLite3
- Telegram Bot API
- OpenAI API ключ (настроен)

## Установка и запуск

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Настройте конфигурацию в файле `config.py`:
   - Добавьте токен вашего Telegram бота
   - OpenAI API ключ уже настроен
4. Запустите бота:
```bash
python bot.py
```

## Структура проекта

- `bot.py` - основной файл бота
- `config.py` - конфигурация и настройки
- `database.py` - работа с базой данных
- `openai_api.py` - интеграция с OpenAI API

## Конфигурация

В файле `config.py` необходимо указать:
- Токен Telegram бота
- OpenAI API ключ (уже настроен)
- Настройки персонажей и стилей общения
